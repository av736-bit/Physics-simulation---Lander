# Mars Lander Simulator

A C++ simulation of a lander descending and landing on Mars.

The simulation models the lander's motion under:

- Mars' gravitational field
- Engine thrust and throttle control
- Atmospheric drag
- Parachute deployment
- Changing lander mass
- Numerical integration using the Verlet method

I have also implemented an autopilot using proportional control to adjust the engine throttle based on altitude and descent rate.

Trajectory data can be recorded and exported for analysis, allowing the effect of different controller parameters to be investigated.

This project was developed as part of my first-year Engineering course at the University of Cambridge, combining mechanics, numerical methods and C++ programming.

**Language:** C++
**Topics:** Mechanics, numerical integration, control systems, aerospace engineering
